**数据源**：`1-1026.txt`（Web of Science 自定义导出，含题目 TI、摘要 AB、作者关键词 DE、Keywords Plus ID，共 1026 条，其中 3 条无摘要）
**研究主题**：城市供水-电力耦合系统级联运行机理与韧性优化
**筛选日期**：2026-09-15 ～ 2026-09-16（B 类终筛完成）

## 一、判定口径（最终）

- **严格口径**：仅"供水侧与电力系统的耦合/互依"算相关，且——
  - **"水"必须是市政供水/配水网**：饮用水供给、供水管网（WDS）、泵站、取水/制水环节；
  - **"电"必须是城市电力系统**：输配电网、城市供电系统；
  - **耦合必须是实质性的**：级联失效机理、互依建模、耦合运行/调度/规划优化、韧性评估与提升、灾后恢复重建等。
- **明确排除**（即使同时出现"水"和"电"）：
  1. 非城市供水（灌溉、农村、离网提水）；
  2. 水力发电、供水系统内能量回收（PAT/微型水电/抽蓄设备）；
  3. 淡化水（可再生供电+淡化制水独立系统、淡化厂联产、淡化供水链规划）；
  4. 社区/海岛/校园/建筑级微型水电系统（电侧非城市电力系统）;
  5. nexus 资源侧（电厂冷却水、水库群调度、水电联调、区域水资源-电力规划）；
  6. 污水处理、雨水/排水系统（单独与电力的耦合，口径外）；
  7. 通用多生命线/相依基础设施方法、调查或社会经济影响研究（未对市政供水-城市电力耦合做实质建模）。
- **B 类处置**：第一轮"保留并标注"的 141 篇 B 类边界文献，已按上述最终口径**逐篇阅读摘要完成终筛**，B 类不再单列——14 篇升入 A 类保留，127 篇剔除（标签含"[B终筛剔除:原因]"，可按原因批量捞回）。

## 三、筛选流程（四轮）

1. **解析**：从 WoS 标记格式提取全部 1026 条的题目、摘要、两类关键词、UT 号。
2. **第一遍（全量）**：逐篇阅读**题目 + 关键词**，判为 A / B / X / 需读摘要（N）；81 篇需读摘要后终判。
3. **质检**：对 X 类中"水+电"共现的 225 条按剔除理由归类抽查，54 条逐篇复核，纠正 1 条。
4. **多系统耦合捞回（第 2 轮）**：三轮定向扫描 X 类（187→31 精读；43 篇补充；110 篇兜底），捞回 6 篇。
5. **B 类终筛（第 3 轮，本次）**：141 篇 B 类逐篇精读摘要（含截断处上下文），按"市政供水/配水网 × 城市电力系统 × 实质耦合"三要素终判：14 升 A、127 剔 X。
6. **重复检查**：无 UT 重复；#617 与 #618 题目完全相同（均 X 类），建议后续去重。
